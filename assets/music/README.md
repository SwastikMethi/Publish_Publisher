# Background music

Drop one or more audio files here (`.mp3`, `.m4a`, `.wav`). The render step picks one, trims
it to the video length, fades it in and out, and mixes it at about -20 dB under the demo.

Only add tracks you are licensed to use on LinkedIn. Royalty-free libraries with a clear
licence (for example the YouTube Audio Library, Pixabay Music, or a paid subscription) are
fine; a song from your own library is not, and LinkedIn mutes or removes videos with
flagged audio. Keep a note of the source next to each file, like `calm-01.SOURCE.txt`.

If this folder is empty the video renders silent and the skill tells you.
